Welcome to ampDOS: An operating system for the z80 AMPRO Little Board. 
HELP lists most OScommands.  Run SETUP to find out what your terminal
can do on the screen.

In the root directory:
  HELLO     the smallest program, an example
  IMGWRITE  writes a fulldisk image sent from a PC
  BASIC     NASCOM style BASIC 4.7 (credit: Grant Searle)
  SETUP     tells ampDOS what the terminal can do

In \BIN you will find extra programs.  Type just their name to run.  
  EDIT     a line editor             DISASM    a disassembler
  MON       machine code monitor     ASM       an assembler
  DISKED    a sector editor          ATTRIB    shows, sets file attributes
  TREE      the directory tree       XCOPY     copies a directory tree
  UNDELETE  recover a deleted file   HEAD      the first lines of a file
  TAIL      last lines of a file.    TR        changes, deletes characters
  DIFF      compares two text files  DISKCOMP  compares two disks
  DUMP      hex dump a file          HEXED     a full-screen hex editor
  DEFRAG    disk's map; defragments  SCANDISK  reads sectors, finds bad 
  MEMMAP    a map of the memory      ASCII     the ASCII table

AMPDOS.SYS is the OS kernel and shell.
