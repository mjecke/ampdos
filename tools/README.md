# Tools
Under /pc/ you will find user scripts I have been using to communicate with the
AMPRO Little Board over its Serial B port from my host machine duiring my
development of ampDOS. 

serxfer.py is a way to talk with the SERRECV and SERSEND programs in ampDOS, to 
trasnfer files.  It is essentially like my version of XMODEM.

Inside /build/ are scipts used by the main build.py - scripts to pack disk img's
and a script that packs the boot banner ASCII art.
